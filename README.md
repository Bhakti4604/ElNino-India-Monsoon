
# El Niño & India's Monsoon

## Overview
An interactive climate analytics project exploring the
historical relationship between El Niño–Southern Oscillation
(ENSO) phases and India's monsoon rainfall variability.

## Objectives
- Analyse historical El Niño and La Niña phases.
- Compare ENSO phases with Indian rainfall patterns.
- Identify regional rainfall anomalies.
- Communicate climate awareness insights through Power BI.

## Technology Stack
- Power BI
- DAX
- Python
- Git and GitHub

## Data Sources
- NOAA Climate Prediction Center
- India Meteorological Department (IMD)

## Project Status
Initial repository setup. Data acquisition and validation
are pending.

## Important Note
The project studies historical relationships. It does not
assume that El Niño always causes deficient Indian monsoon
rainfall, and its findings should not be interpreted as
deterministic forecasts.
